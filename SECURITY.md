# Security Policy

## Supported Versions

This repository is currently released as a research-preview CLI. Security fixes
are targeted at the latest `0.1.x` release line.

## Reporting a Vulnerability

If GitHub Security Advisories are enabled for this repository, please use a
private advisory. Otherwise, open an issue with enough information to reproduce
the problem, but do not include exploit payloads, secrets, or vulnerable
third-party firmware images that you are not allowed to share.

For vulnerabilities found in firmware analyzed with firmddle, follow the
vendor's coordinated disclosure process. firmddle output is triage evidence, not
a complete proof of exploitability.

## Responsible Use

Use this toolkit only for firmware you own, are authorized to test, or are
analyzing for legitimate research and defensive purposes. The maintainers do not
support using this project for unauthorized access, persistence, or exploitation.
